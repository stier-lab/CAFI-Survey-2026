# CAFI Survey Analysis

**Colony size drives sublinear scaling, compositional turnover, and biodiversity--condition feedbacks in coral-associated fauna**

Stier, A.C., Primo, A., Curtis, J.S., Osenberg, C.W.

*Target: Journal of Animal Ecology*

---

## Overview

114 *Pocillopora* coral colonies surveyed across 3 reef sites in Mo'orea, French Polynesia (Summer 2019). ~4,000 CAFI specimens spanning 243 OTUs.

| Question | Key Result |
|----------|------------|
| **Q1: Scaling** | Abundance scales sublinearly with coral size (beta = 0.52); Propagule Redirection, not Field of Dreams |
| **Q2: Composition** | Site pools + size gradient structure composition (db-RDA: 7.8%, p = 0.001); species turn over, not nest |
| **Q3: Feedbacks** | Species richness predicts coral condition (p = 0.018); BEF complementarity vs. abundance artifact unresolved |

## Quick Start

```r
# Prerequisites: R 4.0+ with tidyverse, vegan, MASS, car, patchwork, DHARMa, etc.
# Full package list in scripts/00_setup.R

# Run the complete pipeline (~12 min):
source("scripts/run_full_pipeline.R")
run_pipeline()

# Fast iteration:
run_one("09")       # Single script (~5 sec, auto-loads setup + data)
run_from("06")      # Scripts 06-13 (~25 sec)
run_quick()         # Skip slow scripts 02+05 (~42 sec, needs prior full run)
```
